# ClientFlow CRM

Итоговый React-проект по теме «CRM для клиентов».

## Стек
React, Vite, React Router DOM, Context API, Express, JSON, JWT HttpOnly Cookie, bcryptjs, DummyJSON.

## Запуск
1. `npm install`
2. `cd client && npm install`
3. `cd ../server && npm install`
4. Вернуться в корень и выполнить `npm run dev`

Frontend: http://localhost:5173
Backend: http://localhost:5000

## Маршруты
/ — главная
/register — регистрация
/login — вход
/clients — публичный список клиентов
/clients/:id — карточка клиента
/dashboard — защищённый кабинет
/clients/new — создание
/clients/:id/edit — редактирование
/explore — внешний API
/admin — администрирование
/403 — отказ в доступе
* — 404

Первый зарегистрированный пользователь получает роль admin. Остальные получают user.
Основной CRUD сохраняется в `server/data/db.json` и не использует localStorage как сервер.


## Клубы и менеджеры

- В разделе **Клубы / Добавить клуб** пользователь с аккаунтом может создать клуб. Обязательны название, адрес и контакты; описание, ссылки на фотографии и соцсети необязательны.
- Создатель становится менеджером созданного клуба. Администратор сайта видит все клубы; менеджеры — только клубы, в которых им выдан доступ.
- В карточке клуба выберите его активным. Запросы CRM передают `X-Club-Id`, а сервер проверяет членство и фильтрует клиентов и задачи по `clubId`.
- В разделе менеджеров ищите пользователей по логину (по умолчанию логин — часть email до `@`, если аккаунт был создан до появления отдельного поля логина). Добавлять менеджеров может администратор сайта или менеджер выбранного клуба.
- Клиентские записи и задачи привязаны к клубу. Сервер не отдаёт записи другого клуба и отклоняет доступ к чужому клубу без членства.
- При первом запуске существующие записи перенесены в клуб `club_default` («Основной клуб»). Администратор сайта может выбрать его и назначить менеджеров.

## Работа клуба и тарифы

- Откройте пункт меню **Работа клуба**. Доступ к управлению посетителями есть у администратора сайта и менеджера выбранного клуба.
- Сервер раз в 25 секунд загружает пользователей из `https://dummyjson.com/users?limit=100` и добавляет посетителей в очередь каждого созданного клуба. Для работы генератора серверу нужен доступ в интернет.
- Для принятия посетителя выберите компьютер или VIP-комнату, тариф и длительность. Тариф **Безлимит** не имеет времени окончания.
- Текущие клиенты обновляются автоматически каждые 5 секунд. При истечении времени запись получает статус «Тариф истёк», поднимается вверх списка и появляется уведомление. Можно продлить тариф или закрыть клиента; закрытые клиенты скрыты.
- Очередь, назначенные места и тарифы сохраняются в `server/data/db.json`. Для реальной эксплуатации следует заменить JSON-файл на транзакционную БД и связать список доступных компьютеров/VIP-комнат с настройками каждого клуба.


### Карта клуба и занятость мест

Карта клуба находится в разделе «Работа клуба». Администратор сайта может настроить число компьютеров и VIP-комнат в этом разделе. При назначении места новому посетителю показываются только свободные компьютеры/VIP-комнаты. Принятый посетитель занимает место на карте; после закрытия клиента место снова становится свободным. Названия мест нормализуются в формат `PC-01`, `VIP-01`, в том числе для старых записей вида `Компьютер 1` и `VIP-комната 1`. Сервер дополнительно проверяет занятость места при принятии, чтобы предотвратить двойное назначение.
